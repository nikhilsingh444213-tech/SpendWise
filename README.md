\# 💰 SpendWise — Personal Finance Tracker



SpendWise is a personal finance tracking application designed to help users manage their transactions and keep track of their spending through a simple, user-friendly interface.



\## ✨ Features



\- Add new transactions

\- Edit and delete transactions

\- View recorded transactions

\- Track expenses through a dashboard

\- Store transaction data using PostgreSQL



\## 🛠️ Tech Stack



\- \*\*Frontend:\*\* React, Vite, CSS

\- \*\*Backend:\*\* Node.js, Express.js

\- \*\*Database:\*\* PostgreSQL

\- \*\*Tools:\*\* Git, GitHub, npm

\## 🚀 Getting Started



\### Prerequisites



Install Node.js, npm, and PostgreSQL before running the project.



\### 1. Clone the repository



```bash

git clone https://github.com/nikhilsingh444213-tech/SpendWise.git

cd SpendWise

```



\### 2. Set up the backend



```bash

cd backend

npm install

npm run dev

```



Configure the required database connection settings in `backend/.env` before starting the backend. Use the environment variable names expected by your backend code.



\### 3. Set up the frontend



Open a second terminal and run:



```bash

cd D:\\SpendWise\\frontend

npm install

npm run dev

```



Open the local URL shown in the frontend terminal to use the application.



\## 🔐 Environment Variables



Keep database credentials and other secrets in your local `.env` file. Never commit passwords, database credentials, or API keys to GitHub.
